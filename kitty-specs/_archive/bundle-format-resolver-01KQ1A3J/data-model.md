# Data Model (Discovery Draft) — Bundle Format and Resolver

## Entities

### Entity: BundleManifest
- **Description**: declarative top-level descriptor for a bundle. YAML 1.2; conforms to the published JSON Schema.
- **Attributes**:
  - `schema_version` (int) — bumped on incompatible schema changes.
  - `name` (string)
  - `version` (semver string)
  - `license` (SPDX id)
  - `dependencies` (list of BundleReference) — bundles this one needs.
  - `artifacts` (list of ArtifactDescriptor)
  - `signatures` (list of SignatureRef, optional) — Sigstore or detached Ed25519.
  - `metadata` (map) — author, homepage, repo URL, description.
- **Identifiers**: `(name, version)` plus content hash.
- **Lifecycle**: authored, validated against schema, packaged, signed, distributed, fetched, verified, locked, activated.

### Entity: ArtifactDescriptor
- **Description**: one named artifact within a bundle, of a registered kind.
- **Attributes**:
  - `name` (string) — unique within the bundle.
  - `kind` (string) — registered artifact-kind id.
  - `path` (relative path within bundle root) — must not escape bundle root.
  - `content_hash` (SHA-256) — verified at activation.
  - `kind_metadata` (kind-specific structure)
- **Identifiers**: `(bundle_name, bundle_version, name)`.
- **Lifecycle**: declared at authoring; verified at activation; loaded by the kind handler.

### Entity: ArtifactKindHandler
- **Description**: registered handler that knows how to parse, validate, and activate a category of artifact.
- **Attributes**:
  - `kind` (string)
  - `param_schema` (JSON Schema)
  - `parser`, `validator`, `activator` (function refs)
- **Lifecycle**: registered at startup; consulted by resolver during activation.

### Entity: DistributionChannel
- **Description**: a source of bundles. Implements the channel contract.
- **Attributes**:
  - `kind` (enum: `git`, `oci`, `http_mirror`, `local_path`)
  - `endpoint` (kind-specific) — URL, registry reference, file path.
  - `auth_ref` (CredentialReference, optional) — via `secrets-keychain`.
- **Implementations (v1)**:
  - **`oci`**: backed by `oras.land/oras-go/v2`; auth via docker-credential-helpers.
  - **`git`**: backed by `go-git`; supports HTTPS / SSH refs.
  - **`http_mirror`**: HTTP(S) GET with content-hash verification.
  - **`local_path`**: filesystem read.
- **Lifecycle**: declared at config; reachability validated at pre-flight.

### Entity: Lockfile (`kaneaz.lock`)
- **Description**: TOML file at project root pinning the resolved bundle graph.
- **Attributes**:
  - `schema_version` (int)
  - `[[bundle]]` (array of tables — flat, Cargo-style):
    - `name`, `version`, `source` (channel-qualified URL), `content_hash` (SHA-256), `signature_ref` (optional), `dependencies` (list of `(name, version)`).
  - `[universal]` — markers indicating cross-platform compatibility (uv-lock-style universal model).
- **Lifecycle**: regenerated by resolver; deterministic sort by `(name, version, source)` byte-wise; conflicts resolved via `kaneaz lock --resolve-conflicts`.

### Entity: ResolvedGraph
- **Description**: byte-stable result of one resolver run.
- **Attributes**:
  - `snapshot_id` (ULID)
  - `bundles` (list of BundleManifest, with content hashes)
  - `activation_order` (deterministic sequence)
  - `resolution_metadata` (timing, channels used, cache hit/miss per artifact)
  - `content_hash` (hash of canonical serialization)
- **Lifecycle**: produced at every resolve; referenced by event log entries to make replay deterministic.

### Entity: SignatureRef
- **Description**: pointer to a signature attached to a bundle or artifact.
- **Attributes**:
  - `kind` (enum: `sigstore_referrer`, `ed25519_detached`)
  - `locator` (kind-specific) — OCI referrer reference for sigstore, file path or content hash for ed25519.
  - `algorithm` (string)
  - `key_id` (string, optional) — for ed25519.
- **Lifecycle**: emitted at sign time; verified at activation per `a2a-signed-cards-trust` verification API.

### Entity: BundleEvent
- **Description**: append-only event log entry per `event-log-01KQ1A3M`.
- **Kinds**: `bundle_resolved`, `artifact_fetched`, `artifact_verified`, `artifact_activated`, `artifact_rejected`, `bundle_signature_verified`, `bundle_signature_failed`, `lockfile_updated`, `cache_hit`, `cache_miss`, `channel_unreachable`.

## Relationships

| Source | Relation | Target | Cardinality | Notes |
|---|---|---|---|---|
| BundleManifest | declares | ArtifactDescriptor | 1:N | Per bundle. |
| ArtifactDescriptor | dispatched to | ArtifactKindHandler | N:1 | Routed by `kind`. |
| BundleManifest | depends on | BundleReference (other bundle) | 0:N | Forms the dependency graph. |
| BundleManifest | resolved through | DistributionChannel | N:1 per fetch | Chosen by config + lockfile. |
| Resolution | emits | ResolvedGraph | 1:1 | Per resolver run. |
| ResolvedGraph | referenced by | Event log entries | 1:N | For replay determinism. |
| Lockfile | pins | (BundleManifest, content_hash) | 1:N | Source of truth for "what we got." |
| BundleManifest | optionally signed by | SignatureRef | 0:N | Sigstore or detached Ed25519. |
| SignatureRef | verified through | a2a-signed-cards-trust verification API | 1:1 | Single shared trust primitive. |
| Resolution | emits | BundleEvent | 1:N | Audit trail. |

## Validation & Governance

- **Data quality**:
  - Manifest MUST validate against the published JSON Schema before any bytes are activated.
  - Artifact paths MUST NOT escape bundle root (path-traversal protection).
  - Two artifacts in a bundle MUST NOT share a `(kind, name)` tuple.
  - Circular bundle dependencies MUST be detected and rejected with the cycle path identified.
  - Lockfile sort MUST be deterministic byte-wise; locale-sensitive comparison is forbidden.
  - 100 % of activated artifacts MUST have content hashes verified against the lockfile.
- **Compliance**:
  - Operator policy MAY require signatures; in that case unsigned bundles fail before any artifact is fetched.
  - Resolution events emit through the append-only event log per charter C-003.
  - Sigstore keyless signing leverages OIDC; offline Ed25519 path is the fallback for OSS contributors and air-gapped environments.
  - SLSA target: Build Track Level 2 for v1 (signed provenance from hosted builder).
- **Source of truth**:
  - The Lockfile is authoritative for the resolved graph at any commit.
  - The DistributionChannel is authoritative for the artifact bytes (verified by content hash).
  - The event log is authoritative for resolution history.
