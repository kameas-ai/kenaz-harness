# fire-01PMZ202 WP26).
#
# Enforced by scripts/ci/check-config-nil-coverage.sh /
# scripts/ci/cmd/checkconfig. A struct field that is declared, read, and
# never assigned in production — twenty of the finalizing mission's 29
# findings were exactly this shape (spec.md §10). Two tiers, both
# gating:
#
#   Tier 1: an exported struct type under core/ named Config, Options,
#   GateOptions or Deps, constructed in >=1 non-test composite literal,
#   with a pointer/interface/func/map/chan/slice field set in ZERO
#   non-test sites (a composite-literal key OR a plain `x.Field = v`
#   assignment outside the struct's own methods — see main.go's header
#   for why the plain-assignment clause is required, not optional: it
#   is the DOMINANT wiring idiom for corewf.Deps).
#
#   Tier 2: an exported With* function/method under core/ whose first
#   parameter is a non-empty interface (the "injected collaborator"
#   shape all five of the spec's own named examples share — see
#   main.go's header for why this interface-typed-first-arg
#   restriction exists: an unrestricted "every With* func" scan finds
#   ~200 candidates dominated by test-only mock-injection knobs
#   (*http.Client, string endpoints, clock funcs) that are a normal Go
#   idiom, not this defect class), with zero non-test callers anywhere
#   under core/.
#
# NAMING NOTE: the WP26 spec text names this allowlist
# "i16-nil-optional-deps.txt" — but that literal filename collides
# conceptually with the ALREADY-SHIPPED, unrelated
# i18-nil-optional-deps.txt (a different gate, check-nil-optional-
# deps.sh / checknilopts, triggered by a doc-comment phrase on ANY

# numbering slot (I16), self-describing suffix.
#
# Format (RE-KEYED 2026-09-14, Finding #92, CI-gate-hardening): one
# FULLY-QUALIFIED SYMBOL per entry — `<pkgPath>.<Struct>.<Field>` for

# description` locator comment (copy it verbatim from the gate's FAIL
