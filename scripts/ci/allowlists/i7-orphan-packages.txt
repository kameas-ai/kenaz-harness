# I7 allowlist — non-test packages under core/ with zero non-test importer
# and no `main` package of their own (spec §6 I7: "every non-test package
# has a non-test importer or is an entry point").
#
# Computed by: `go list -json ./core/... ./cmd/...` (module-internal
# `Imports` edges, which are non-test-only by definition) UNION the
# repo-root main.go's own import block (extracted by grep, since
# `go list ./...` cannot resolve main.go's `//go:embed all:frontend/dist`
# on a checkout that has not run a frontend build).
#
# This is a coarse, mechanical definition, not an individual verdict on
# each package's architectural merit. Some entries are almost certainly
# legitimate test-support libraries that are only ever imported from
# _test.go files elsewhere (e.g. core/mcp/fixture, core/bundle/kinds/testkind)
# — which is precisely what I7 is designed to surface, since a package
# whose only purpose is being imported by tests is easy to mistake for
# live production code. Others may be genuinely dead, or reachable only
# behind a build tag the default build does not select (worth checking
# individually — see core/otel, confirmed by hand during WP01 to be
# imported only by its own _test.go file today).
#
# Each entry is deleted by whichever WP gives the package a real non-test
# importer, folds it into its caller, or deletes it outright.
#
