#
#   Evaluates ManifestDriftWarnings against the configured dial mode and
#   returns ErrManifestDrift when mode=block (manifest_drift_dial.go:49).

#   CORRECTION, 2026-08-14 (unwired sweep). WP17's justification for
#   keeping this line said: "the dial ships in

#   cascade". THE SECOND HALF WAS FALSE — applyLayer had branches for
#   twelve DialConfig fields and none for ManifestDriftMode, and
#   EffectiveDials had no such field, so the value could not survive
#   Resolve() even in principle.
#
#   SUPERSEDED, 2026-08-14 (orphan-deletion sweep wave 2). The dials
#   cascade has been DELETED — core/agentgraph/dials and
#   core/rpc/views/dials are gone, along with the Dials_* bindings and
#   DialsView.vue. Rubric class: rival infrastructure (core/autonomy is

#   the kernel's budget comes from graph.Budget folded with the autonomy
#   token-ceiling knob in chat_runner.go, never from EffectiveDials).
